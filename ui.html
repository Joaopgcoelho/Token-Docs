Navegação entre Collections

Use o painel lateral esquerdo para selecionar uma collection. Cada collection agrupa tokens relacionados (cores, tipografia, espaçamento). Clique no nome da collection para visualizar seus tokens.

Alternando entre Modos

Use os chips de modo (ex: Light, Dark) na barra acima dos tokens para alternar entre as variações de cada collection. Os valores dos tokens mudam conforme o modo selecionado.

Busca de Tokens

Use o campo de busca para filtrar tokens pelo nome. A busca é instantânea e filtra enquanto você digita.

O que a Auditoria Verifica

A auditoria escaneia os nós (componentes, frames, textos) da página e verifica se os tokens de design estão sendo usados corretamente. Detecta valores brutos sem token, tokens de camada incorreta e tipos incompatíveis.

Níveis de Severidade

  • Error — Problema crítico: valor bruto sem token ou token Base/Foundations usado diretamente em UI. Deve ser corrigido.
  • Warning — Atenção: token Brand usado onde Usage seria mais apropriado, ou tipo de token incompatível com a propriedade.
  • Suggestion — Sugestão de melhoria: token de Component usado fora do contexto System Ops, ou oportunidade de usar um token mais específico.

Aplicando Correções

Clique em "Corrigir" ao lado de cada issue para aplicar a correção sugerida automaticamente. Use "Corrigir Todos" para aplicar todas as correções de uma vez. Clique em "Selecionar" para navegar até o nó afetado no canvas.

Como Carregar Dados

Existem três formas de carregar tokens do Storybook/npm para comparação:

  • Buscar Tokens do Storybook — Busca automática dos tokens publicados no Storybook via URL configurada.
  • Carregar Arquivo JSON — Selecione um arquivo .json local com os tokens exportados do pacote npm.
  • Colar JSON de Tokens — Cole diretamente o conteúdo JSON dos tokens do pacote @lift/ds-tokens.

Status de Comparação

  • OK — Token existe em ambos (Figma e npm) com o mesmo valor.
  • Divergente — Token existe em ambos mas com valores diferentes.
  • Ausente — Token existe no Figma mas não foi encontrado no npm.
  • Novo — Token existe no npm mas não foi encontrado no Figma.

Interpretando Resultados

Os chips de resumo no topo mostram a contagem de cada status. Tokens divergentes e ausentes devem ser investigados — podem indicar que o pacote npm está desatualizado ou que tokens foram renomeados.

Como Carregar Dados

A verificação de divergências compara tokens do Figma com os do pacote npm. Você precisa carregar dados de ambas as fontes:

  • Dados Figma: Use "Sincronizar Documentação Enriquecida" para carregar dados diretamente dos boards no canvas, ou "Carregar JSON Figma" para selecionar o arquivo tokens-figma-enriched.json.
  • Dados npm: Use "Carregar JSON npm" para selecionar o arquivo tokens-all-brands.json do pacote npm.

Interpretando o Relatório

  • Apenas no Figma — Tokens que existem no Figma mas não no npm. Podem ser tokens novos que ainda não foram publicados.
  • Apenas no npm — Tokens que existem no npm mas não no Figma. Podem ser tokens removidos ou renomeados no Figma.
  • Valor Diferente — Tokens que existem em ambos mas com valores diferentes. Indica que o Figma ou o npm está desatualizado.

Monitoramento em Tempo Real

Ative o "Monitoramento em Tempo Real" para que o plugin detecte automaticamente quando tokens são alterados no Figma. Mudanças detectadas aparecem na área de notificações acima dos resultados. Útil durante sessões de design para garantir que alterações sejam rastreadas.
